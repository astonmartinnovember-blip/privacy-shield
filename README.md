# 🛡️ Privacy Shield

Жарнамалар мен трекерлерді блоктауға арналған жеңіл әрі қарапайым Chrome кеңейтімі.

## ✨ Мүмкіндіктері

- 🛡️ Жарнамалар мен трекерлерді блоктау
- ▶️ YouTube-тағы жарнамаларды сүзу
- ⏭️ Мүмкін болған жағдайда жарнаманы автоматты түрде өткізіп жіберу
- 🔘 Қорғанысты ON/OFF режимінде басқару
- 📊 Блокталған сұраныстар санын көрсету
- ⚡ Жеңіл және жылдам жұмыс
- 🔒 Қолдану үшін аккаунт қажет емес

## 🚀 Орнату

### Тестілеу үшін

1. Репозиторийді жүктеп алыңыз.
2. ZIP архивін ашыңыз.
3. Chrome браузерінде:
   `chrome://extensions`
   мекенжайына кіріңіз.
4. **Developer mode** режимін қосыңыз.
5. **Load unpacked** батырмасын басыңыз.
6. Ішінде `manifest.json` орналасқан папканы таңдаңыз.
